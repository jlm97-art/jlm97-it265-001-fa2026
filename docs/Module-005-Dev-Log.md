#### Progress
- **What I accomplished**:
  - Decided on a board size and shape for my physical prototype
    - The board will be split into three triangular islands (or "cities" to match the game's theme), in which each corner-to-corner step count of each island will be
      7x3, for a total of 63 spaces.
    - I decided on this board space instead of one huge board to make accessing the board from all angles easier.
    - Each island will have a set amount of event spaces, as well as a random amount of currency collectibles.
    - All islands will be connected to each other, in which there will be an island in the middle that will only be accessible once
      the player has a certain amount of the currency collectible. This island can be accessed via three tiles, one per island, that will be represented
      by a label that changes per session for a sense of semi-prodecurely generated board.
- **Challenges faced**:
  - Difficulty on deciding the board size at first in order to make sure that the average spaces move cover a reasonable amount of the board.
- **Solutions**:
  - Ultimately decided on the triangular islands concept in order to even out the amount of spaces and to not overwhelm the player with a large space.
