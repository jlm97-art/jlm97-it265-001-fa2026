#### Learnings
- Board games heavily utilize tiles and tile maps,
- Multiple tiles make up a tile map, whether it be paths towards different tiles, or interactive (effect-bringing) tiles
- Tiles have rules, whether it be a specific geometric shape or having its own effects, decorations, or collisions
- Graphics can also help define tile(sets), such as shaders and textures in order to help define the significance of a particular tile
