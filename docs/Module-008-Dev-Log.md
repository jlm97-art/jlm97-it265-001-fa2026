#### Learnings
- From case study, player needs to have a variety of options and alternatives to approach a challenge.
- These options need to have meaning, they need to have their own tradeoffs, benefits, later consequences, or gameplay loop
  changes that make choosing them worthwhile within a given situation for the current game session
- Having two similar decisions that lead to one outcome does not promote agency in a game.
- A game engine contains all the necessary systems for the functioning of a game.
- This may include audio, control scheme, rendering, or scripting of a given game.
- How each system is structured for a given game is reliant on the planned player actions, gameplay loop, current ruleset, and
  feedback from iterations
  Examples of game engines may include Godot, Unity, Unreal Engine, or GameMaker. What differentiates these game engines from
  each other is their focus on different workflows, most notably their focus in different scripting languages or dimensions (2D/3D).
