**Relevance today: Still relevant** 

**Reason and supporting example: As this verison of my board game is the prototype, feasibility is a major factor in the development phase as it focuses on what elements should be kept in for the final product, changed, or removed entirely.
Feasibility is also important in the sense that the proposed features and concepts for a game may hold the opportunity to be reinvented or heavily modified to make a game unique. An example that supports the idea of feasibility in today's gaming industry is the tile-based video game "2048". While not a board game, it is a rather simplistic merger video game that includes few yet critical features (primarily the small grid space constraint, the score, and merging tiles). Such a game demonstrates how features can still be made not only feasible, but crucial for making the game enjoyable given the constraints. **
